# 防摸鱼T+1数据接口说明文档

## 总数据结构

所有接口都添加了`SocketUserId`字段，需要每条数据落表`socketUserId`字段。

```json
{
  "params": "提交参数,需要保存,参考live_account_info表",
  "cookies": "身份信息，需要保存,参考live_account_info表",
  "fromUrl": "请求的URL",
  "extra": "提交的额外参数",
  "sign": "身份验证标识(数仓可以忽略)",
  "socketUserId": "插件唯一标识ID(用于和和账号弱绑定使用)",
  "userType": "用户类型(用于判断数据来源是客户账号还是普通TT账号,数仓应该用不到,可以忽略)",
  "updateTime": "获取数据的时间戳",
  "request": {
    "response": "真正的数据json",
    "url": "实际请求的API链接"
  }
}
```

## 不同接口对应数据说明

接口判断规则：基于`from_url`、`stats_types`、`period`参数来判断是哪个接口返回数据。

| 接口名 | from_url | stats_types | period | 备注 |
|-------|---------|------------|--------|------|
| 直播间列表 | /api/v2/insights/creator/live/list | | 33 | |
| 关键指标 | /api/v2/insights/creator/live/stats | | | |
| 直播间详情-关键指标 | /api/v1/insights/creator/liveroom/recap/core/stats | | | |
| 直播间详情-商品分析-成交趋势 | /api/v1/insights/creator/liveroom/recap/trend/chart | | 52 | |
| 直播间详情-流量分析-流量趋势 | /api/v1/insights/creator/liveroom/recap/trend/chart | | 60/61 | |
| 直播间详情-内容分析-直播趋势 | /api/v1/insights/creator/liveroom/recap/trend/chart | | | |

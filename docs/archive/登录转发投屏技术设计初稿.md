# 登录转发投屏技术设计（简版）

## 1. 目标与范围
- 目标：在创建的浏览器环境中完成登录并实时投屏，前端可低延迟查看登录过程；登录成功后完成校验与回传。
- 范围：
  - 基于 CDP Screencast 的投屏链路
  - FastAPI 服务新增：创建环境、启动浏览器、建立 WS、关闭浏览器
- 非目标：账号登录逻辑自动化、前端 UI 细节、持久化存储设计
- 注意：事实上我伪后端，嵌套多了一层后端，不是直接对接前端的。所以无需考虑一些业务相关的东西 我只需要实现登录这个核心过程，相关db操作在业务后端操作

## 2. 技术栈
- 后端Fasrapi
- 浏览器 DrissionPage 
- 相关文档查阅：
  - 请使用context7 查找adspower相关的新建浏览器V2、启动浏览器V2、删除环境V2、修改分组和查找drissionpage浏览器相关的操作


## 3. 组织架构

### 3.1 组件职责
- **FastAPI 服务**
  - 环境管理：调用 adspower 创建/启动/关闭浏览器
  - CDP 连接管理：建立 CDP WS、启动 screencast、转发帧
  - 业务监听：登录成功检测与回传
- **Chrome/Adspower**
  - 通过 `--remote-debugging-port` 开启 CDP
- **前端**
  - WebSocket 接收帧并渲染

## 4. 关键流程

### 4.1 新建并启动浏览器环境
- 输入：国家、广告主名称、媒体、直播账号、直播间地址
  - 可选参数 `profile_id`
- 行为：
  - 调用 adspower API 创建对应国家 IP 的环境【/api/v2/browser-profile/create】, 如果没有对应的国家ip 则返回失败
  - 如果传参有 profile_id 则直接启动浏览器环境
  - 新建环境后得到profile_id，在进行启动浏览器环境【/api/v2/browser-profile/start】
  - 启动完成后打开 TikTok/虾皮登录页（由 adspower 配置或后续自动打开）
- 输出：
  - 成功：包含 `debug_port` 与 `ws`/`webdriver` 信息
  - 失败：`{ data: {}, code: -1, msg: "缺乏该对应国家的ip，创建浏览器失败" }`
  - 失败：`{ code: -1, msg: "Profile does not exist" }`

- 约束：Windows 下每个浏览器实例需唯一 `--remote-debugging-port`，需端口池管理。

### 4.2 建立投屏 WS
- 行为：
  - 前后端建立 WS
  - 后端建立 CDP WS，执行 `Page.startScreencast`
  - 收到帧后直接转发给前端
- 超时：默认 15 分钟无活动自动断开

### 4.4 登录成功监听与回传
- 在独立线程中监听登录成功的网络接口
- 校验登录前信息与登录后信息一致
- 一致则：
  - 回传到指定后端 API
  - 将 adspower 环境加入对应用户组

### 4.6 关闭浏览器
- 成功：`{ code: 0, msg: "success" }`
- 失败：`{ code: -1, msg: "failed" }`
- **清理流程**：
  1. 停止 screencast
  2. 关闭 CDP 连接
  3. 调用 AdsPower 关闭浏览器 API
  4. 释放端口到端口池
  5. 清理 Session 数据

## 5. 接口设计（FastAPI）

### 5.1 通用约定
- Base URL: `/api`
- Content-Type: `application/json`
- 响应格式：`{"code":0,"msg":"success","data":{}}`
- 错误码建议：
  | 错误码 | 说明 |
  |--------|------|
  | 0 | 成功 |
  | -1 | 通用失败 |
  | -2 | 参数错误 |
  | -3 | 端口池耗尽 |
  | -4 | CDP 连接失败 |
  | -5 | Session 不存在或已过期 |
  | -6 | 无对应国家IP |

### 5.2 创建浏览器环境
- POST `/api/browser/profile/create`
- 请求：
```json
{
  "country": "VN",
  "advertiser_name": "广告主A",
  "media": "tiktok",
  "live_account": "xxx",
  "live_room_url": "https://...",
  "profile_id":null
}
```
- 成功响应：
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "session_id": "sess_01H...",
    "ws_url": "wss://host/ws/remote/sess_01H...",
    "ws": {
      "puppeteer": "ws://127.0.0.1:60692/devtools/browser/xxxx",
      "selenium": "127.0.0.1:60692"
    },
    "debug_port": "60692",
    "webdriver": "C:\\\\Users\\\\...\\\\chromedriver.exe"
  }
}
```
- 失败响应1：
```json
{"code":-6,"msg":"缺乏该对应国家的ip，创建浏览器失败","data":{}}
```
- 失败响应2：
```json
{"code":-1,"msg":"Profile does not exist","data":{}}
```

### 5.3 投屏与控制 WS
- WS `/ws/remote/{session_id}`
- 方向：双向
- **连接握手**：
  - 可通过 query 参数传递 token：`/ws/remote/{session_id}?token=xxx`
- **前端 -> 服务端**：
```json
{"type":"input","event":"mouse","x":210,"y":120,"button":"left","action":"down","devicePixelRatio":2}
{"type":"input","event":"key","key":"Enter","action":"down","modifiers":["ctrl"]}
{"type":"resize","width":1280,"height":720,"devicePixelRatio":2}
{"type":"ping","ts":1730000000}
```
- **服务端 -> 前端**：
```json
{"type":"frame","data":"base64...","width":1280,"height":720,"ts":1730000001}
{"type":"control_grant","value":true}
{"type":"pong","ts":1730000000}
{"type":"error","code":-1,"msg":"session expired"}
{"type":"login_success","data":{"uid":"123","nickname":"abc"}}
```
- 超时：默认 15 分钟无心跳/无输入即关闭

### 5.5 关闭浏览器
- POST `/api/browser/profile/close`
- 请求：
```json
{"profile_id":"k1914q68","session_id":"sess_01H..."}
```
- 成功响应：
```json
{"code":0,"msg":"success","data":{}}
```

### 5.6 登录成功回调（内部）
- POST `/api/login/success`
- 说明：由登录监听线程调用业务后端，登录成功采集侧将当前未分组的环境移动到对应的用户组下面，以便每日定时采集
- 请求：
```json
{
  "session_id": "sess_01H...",
  "profile_id": "k1914q68",
  "media": "tiktok",
  "live_account": "xxx",
  "login_info": {"uid":"123","nickname":"abc"}
}
```

## 6. 错误处理与边界
- 端口池耗尽：返回明确错误码与提示
- CDP 连接失败：重试（短时），否则断开 WS
- adspower API 失败：透出原错误信息
- 登录监听超时：主动关闭 WS 并记录原因

## 7. 安全与权限

Patrick Star - Privacy Policy

Last updated: May 2025

1. Information Collection

The Patrick Star plugin collects the following information:

  • TikTok live streaming related data, including but not limited to:
    • Live streaming statistics (viewer count, likes, comments, etc.)
    • Audience interaction data
    • Live streaming duration and time period information
    • Gift and donation data
  • Necessary Cookie information to maintain normal communication with TikTok servers
  • Temporary data generated during plugin usage

2. Information Usage

The information we collect will be used for:

  • Providing live streaming data analysis functionality
  • Optimizing plugin performance and user experience
  • Conducting data analysis and research to improve services
  • Generating statistical reports and trend analysis

3. Data Storage and Transmission

We adopt the following data storage and transmission methods:

  • Data is periodically transmitted to our servers for storage and analysis
  • Some temporary data is retained locally for plugin operation
  • All data transmission uses encryption
  • Data will be stored on our servers for a certain period for continuous analysis and service improvement

4. Data Security

We take the following measures to protect your data:

  • All data transmission uses HTTPS encryption
  • Servers employ strict security measures to protect stored data
  • Regular security audits and updates
  • Restricted data access permissions, only authorized personnel can access

5. User Rights

You have the following rights:

  • Uninstall the plugin at any time, and local data will be cleared
  • Request to view your data stored by us
  • Request deletion of your data
  • Choose whether to allow the plugin to access specific websites

6. Update Notifications

When we update our privacy policy, we will:

  • Notify users during plugin updates
  • Update the last modified date on the privacy policy page
  • Notify important changes via email or other means

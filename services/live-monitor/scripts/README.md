# TikTok 主播国家信息对比脚本使用说明

## 功能

对比 TikTok 主播的国家信息：
- 调用 `/liveRoom/portInfo` 接口获取 `publish_region`（视频发布国家）和 `live_region`（开播国家）
- 与原始 Excel 中的 `country_code` 对比
- 生成包含对比结果的新 Excel 文件
- **多线程并发请求**，大幅提升处理速度

## 使用方法

### 1. 试运行（推荐首次使用）

```bash
cd services/live-monitor
python scripts/sync_tiktok_region.py --dry-run
```

只处理前 5 条 TikTok 数据，用于验证脚本是否正常工作。

### 2. 完整运行

```bash
python scripts/sync_tiktok_region.py
```

处理所有 TikTok 数据（约 420 条），使用 10 个并发线程，预计耗时 1-2 分钟。

### 3. 自定义参数

```bash
python scripts/sync_tiktok_region.py \
  --input scripts/custom_data.xlsx \
  --output scripts/custom_result.xlsx \
  --workers 5
```

参数说明：
- `--input`：输入 Excel 文件路径（默认：`scripts/全部直播账号数据.xlsx`）
- `--output`：输出 Excel 文件路径（默认：`scripts/全部直播账号数据_region对比.xlsx`）
- `--dry-run`：试运行模式（只处理前 5 条）
- `--workers`：最大并发线程数（默认 10，建议 5-20）

## 输出字段

新生成的 Excel 文件包含以下字段：

### 原始字段（保留）
- room_name
- media_user_name
- media_shop_id
- country_code
- room_url
- platform
- base_id
- login_status
- collection_id

### 新增字段
- `publish_region`：视频发布国家（ISO-3166 alpha-2 代码，如 "MY"）
- `live_region`：开播国家（ISO-3166 alpha-2 代码，如 "TH"）
- `region_match`：是否与 country_code 匹配（True/False）
- `api_status`：API 调用状态（"success" / "failed"）
- `error_detail`：失败原因（成功时为空）

## 日志

日志文件位置：`logs/sync_tiktok_region/YYYY-MM-DD.logs`

日志包含：
- 每行处理进度
- API 失败警告
- 网络异常重试
- 最终统计信息（成功数、失败数、匹配数、失败原因分布、耗时统计）

## 性能统计

脚本会自动统计所有 API 请求的性能指标：

- **总耗时**：整个脚本执行时间
- **平均耗时**：单个 API 请求的平均响应时间
- **最短耗时**：最快的 API 请求响应时间
- **最长耗时**：最慢的 API 请求响应时间
- **成功数**：API 调用成功的数量
- **失败数**：API 调用失败的数量

## 注意事项

1. **API 服务必须运行**：脚本依赖 `http://192.168.46.39:8080/liveRoom/portInfo` 接口，确保 `main.py` 已启动
2. **只处理 TikTok 数据**：Shopee 和 Lazada 数据会被跳过（这些平台不返回 region 字段）
3. **多线程并发**：默认 10 个并发线程，可通过 `--workers` 参数调整
4. **错误处理**：API 失败时会记录状态并继续处理下一行，不会中断脚本
5. **重试策略**：
   - 5xxx 错误（上游/内部异常）：最多重试 3 次，指数退避
   - 4xxx 错误（资源不存在/入参错误）：不重试
   - 网络异常：最多重试 3 次，固定间隔 2 秒

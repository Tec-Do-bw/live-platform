# 更新日志

## v2.1 - 完全整合版 (2025-10-20)

### ✨ 新增功能

#### 1. 完全整合的单一启动入口
- **一个命令启动所有服务**：`python main.py`
- `main.py` 自动在后台线程启动 `start_scheduler.py`
- 保持代码模块化，便于维护
- 包含7大核心功能模块：
  - FastAPI Web服务
  - WebSocket实时推送
  - 房间检测任务（每5分钟）
  - 离线脚本监控（每5分钟）
  - **GMV实时采集**（每5分钟）⭐ 新增
  - **T+1插件执行**（每4小时）⭐ 新增
  - **基本信息采集**（每天12点）⭐ 新增

#### 2. 统一的主备切换机制
- 所有定时任务都支持主备自动切换
- 主节点故障时，备节点自动接管所有任务
- 包括：
  - 房间检测 ✅
  - 离线脚本 ✅
  - GMV采集 ✅
  - T+1插件 ✅
  - 基本信息采集 ✅

### 🔧 技术改进

#### 代码整合
- `main.py` 自动在后台线程启动 `start_scheduler.py`
- 保持代码模块化，`start_scheduler.py` 仍可独立运行
- 统一使用 `scheduler_manager` 管理所有定时任务
- 采用线程方式启动，轻量高效

#### 主备切换增强
```python
# 所有任务都使用相同的主备切换逻辑
scheduler_manager = create_scheduler_manager(NODE_ID, NODE_IP)
wrapped_task = scheduler_manager.wrap_task(task_func, "任务名称")
```

#### 容错机制
- 如果 `schedule` 库未安装，会跳过定时任务配置
- 如果 `tasks` 模块不可用，会显示警告但不影响其他功能
- 确保核心Web服务始终可用

### 🎯 主备切换逻辑

#### 主节点（node1）
```
启动 → 执行所有任务 → 同步数据到备节点
      ↓
    正常运行
      ↓
    故障 → 备节点接管
```

#### 备节点（node2）
```
启动 → 监控主节点 → 待命
      ↓
    检测主节点故障（连续3次）
      ↓
    接管所有任务执行
      ↓
    检测主节点恢复 → 停止执行，恢复待命
```

### ⚠️ 重要说明

1. **start_scheduler.py 自动启动**

# adspower-server

> 通用编码规范、交互规范见根 `CLAUDE.md`。项目结构、启动命令、API 清单见 `README.md`。本文仅记录约束与设计决策。

## 项目定位

中间层服务，**不直接与前端交互**。调用链路：前端 → 后端 → FastAPI（本项目）。

## 登录回调约束

### login_status 三种值

| 值 | 含义 | 触发场景 |
|----|------|----------|
| `success` | 登录成功 | 检测到登录成功并验证店铺匹配 |
| `error` | 登录失败 | 超时、店铺不匹配、监听异常等 |
| `closed` | 主动关闭 | API 关闭、WebSocket 断开、应用关闭等（未完成登录流程） |

详细 `reason` 字段说明、Lazada 双端口登录流程、WebSocket 投屏功能见 `../../.claude/rules/login-callback-spec.md`。

## 浏览器环境管理约束

### 关闭浏览器时不删除环境

所有场景下关闭浏览器时，**只调用** `stop_browser()`（仅关闭），**不调用** `cleanup_browser()`（关闭+删除）。

**原因**：创建浏览器时已有自动清理机制（`cleanup_old_profiles`），未分组环境超过阈值时会自动删除最旧环境，无需在关闭时删除。

### 方法语义

| 方法 | 作用 | 使用场景 |
|------|------|----------|
| `stop_browser()` | 仅关闭浏览器，保留环境 | API 关闭、WebSocket 断开、登录完成、应用关闭 |
| `cleanup_browser()` | 关闭并删除环境 | **仅**用于创建失败时的异常回滚 |

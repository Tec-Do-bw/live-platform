## 一、背景与问题

### 当前调度策略
- **执行时间：** 北京时间 04:00 和 20:00（固定两次）
- **问题：** 所有国家统一按北京时间调度，导致部分时区数据获取不及时

### 典型案例
**巴西账号数据延迟问题：**
- 巴西直播时间：4/14 22:00 - 4/15 08:00（巴西时间 UTC-3）
- 换算北京时间：4/14 21:00 - 4/15 07:00（北京时间 UTC+8）
- 当前调度：北京时间 4/15 20:00 才采集
- **延迟：** 直播结束后 13 小时才获取数据

---

## 二、优化方案

### 核心策略
**按时区分组调度** - 每个时区在各自的"本地时间"固定时刻执行采集

### 调度时刻选择
- **第一次：本地 04:00** - 采集 T-1 完整数据（前一天 00:00-23:59）
- **第二次：本地 16:00** - 兜底补采 + 采集当天上午数据

### 优势
1. **数据及时性最优** - T-1 数据在本地日期结束后 4 小时内获取
2. **容错性强** - 两次采集互为备份，降低单次失败风险
3. **业务友好** - 凌晨 4 点是直播低谷期，对在线直播影响最小

## 四、技术实现要点

### 配置结构调整

**原配置（`config_base.py`）：**

    "cron_config": [

### 调度器改造

**核心逻辑：**
1. 读取账号的 `group_name`（如"巴西团队-tiktok"）
2. 根据 `group_name` 匹配时区偏移量（通过 `SHOPEE_COUNTRY_MAP` 或新增 `TIMEZONE_MAP`）
3. 每次定时任务触发时，仅采集匹配当前 `timezone_offset` 的账号

**伪代码：**
```python
def execute_crawl_task(self, timezone_offset: int):
    """执行指定时区的采集任务"""
    for platform, config in platform_configs.items():
        accounts = get_accounts(platform)
        
        # 过滤：仅采集匹配当前时区的账号
        filtered_accounts = [
            acc for acc in accounts 
            if get_account_timezone(acc['group_name']) == timezone_offset
        ]
        
        for account in filtered_accounts:
            crawl(account)
```

## 五、夏令时处理

### 影响国家
- **墨西哥：** 标准时间 UTC-6，夏令时 UTC-5（3月-10月）
- **美国：** 标准时间 UTC-8，夏令时 UTC-7（3月-10月）

### 当前方案
**使用标准时间固定偏移量**
- 夏令时期间实际执行时间会早 1 小时（本地 03:00/15:00）
- 仍能覆盖 T-1 完整数据，对业务影响可接受

### 未来优化（可选）
如需精确处理夏令时，可引入 `pytz` 库动态计算：
```python
from pytz import timezone
from datetime import datetime

def get_local_time(country_code: str) -> datetime:
    tz = timezone('America/Mexico_City')  # 自动处理夏令时
    return datetime.now(tz)
```

### B. 分组命名规范

**当前规范：** `{国家}团队-{平台}`  
**示例：**
- `巴西团队-tiktok`
- `印尼团队-shopee`
- `马来团队-tiktok`

**时区识别逻辑：**
```python
COUNTRY_TIMEZONE_MAP = {
    "日本": 9,
    "中国": 8, "马来": 8, "新加坡": 8, "菲律宾": 8, "台湾": 8,
    "印尼": 7, "泰国": 7, "越南": 7,
    "巴西": -3,
    "墨西哥": -6,
    "美国": -8,
}

def get_account_timezone(group_name: str) -> int:
    for country, offset in COUNTRY_TIMEZONE_MAP.items():
        if country in group_name:
            return offset
    return 8  # 默认 UTC+8
```
